# Бэклог до пред-релиза — черновик zcode (24.10.2026)

Концепция владельца (правила, не обсуждаются): максимально нативная сборка **без внешних зависимостей**; **две темы**; **сайдбары однотипны** во всей линейке; **шапка подстраивается под тему**; **контент и заголовки максимально идентичны** между приложениями. Целевой результат первой очереди — **рабочий нативный плеер** с текущим функционалом и всеми унификациями.

## ПЛЕЕР (приоритет 1 — «реально рабочий нативный плеер»)

- **P1. Тема — одна ось `Look`.** Сейчас две оси (preset aero/obsidian × look light/dark/system) — свести к двум темам + системной: Светлая = системное стекло, Тёмная = плотный матовый. Пикер и в трее, и в окне; хранение — ключ `"look"` пакета. Двойные enum'ы (Theme) — в `Look`.
- **P2. Шапка — системный unified toolbar.** Уже системный; проверить: titlebar-сепаратор под тему, системную адаптацию, убрать кастомное, что дублирует систему. Заголовок/кнопки тулбара — по токенам линейки.
- **P3. Сайдбар — однотипный паттерн линейки.** Системный `NavigationSplitView` (уже есть); строки — `Metrics.row`, шрифты — `Typography`, заголовки секций — label-стиль (капс + трекинг), hover/selection — токенами. Сверить с сайдбарами браузера и редактора на одинаковость.
- **P4. Типографика — все размеры на токены.** В плеере немного (~20 мест): заголовок 15→display-уровень, таймкоды mono, номера треков mono, капсоны плейлистов label.
- **P5. Материалы — по Apple.** Светлая тема: `NSVisualEffectView(.underWindowBackground)` остаётся системным материалом; **самодельные слои lift/sheen/foot — убрать** (Apple: своё стекло под системным хромом не рисуют). Тёмная — плотный `Palette.ground`. Reduce Transparency — системный фолбэк, свой код фолбэка сократить до минимума.
- **P6. Контролы.** Громкость — системный Slider (уже); Door — компонент линейки (добавить a11y-лейблы, valueOn/valueOff уже в пакете); прогресс — свой (легитимный кастом), привести цвета к токенам.
- **P7. Пред-релиз.** Версия 0.2.0 (унификация), NOTES/CHANGELOG, `build.sh release`, полный прогон тестов, обновление рабочей версии владельца.

## БРАУЗЕР (эталон стиля; до пред-релиза — «дизайн-доедание» + его ROADMAP)

- **B1. Typography-adoption**: 226 хардкодов → токены по карте соответствия (поэтапно: панели настроек → хром → контент). Карта — в пакете как таблица соответствий.
- **B2. Сайдбар — к однотипному паттерну** (палитра уже едина; строки/шрифты/отступы — как у плеера/редактора).
- **B3. Материалы по Apple**: SiteCard `.menu` — эталон; кастомное стекло не расширять.
- **B4. Функционал (ROADMAP браузера)**: стартовый экран (приоритет 1: базовый → сетка виджетов → переключатель темы), локальные виджеты, система тем.
- **B5. Пред-релиз**: 1.0.7 «унификация» (или влить в 1.1 со стартовым экраном — развилка для владельца).

## РЕДАКТОР (ранний; до пред-релиза — «дизайн-завершение» + минимум функционала)

- **E1. Настройки**: системное Settings-окно (рецепт пакета) с `LookPicker` — Appearance → `Look`.
- **E2. Сайдбар**: sourceList системный (уже); строки/шрифты — к линейки.
- **E3. Хром**: статус-бар и панель поиска — по рецептам пакета (`Hunt`), единые с линейкой.
- **E4. Функционал**: сессии/недавние — довести WIP до конца; синтакс-подсветка — ⚠️ развилка: tree-sitter = первая внешняя зависимость, против правила «без внешних» → либо своя простая подсветка, либо решение владельца.
- **E5. Пред-релиз**: шаг сборки .app + первая установка (сейчас — дев-версия).

## ОБЩЕЕ (пакет DajetUI)

- **G1. Материалы-рецепт по Apple**: обёртка `NSGlassEffectView` (macOS 26+) с фолбэком `NSVisualEffectView` — для кастомных поверхностей (SiteCard-паттерн).
- **G2. Унификация облика**: Theme (плеер) и Appearance (редактор) → `Look`.
- **G3. A11y-слой**: пройтись по всем компонентам (лейблы, трейты).
- **G4. Тесты-пины расширенные**: геометрия компонентов (Door/Segmented/Pill) после a11y-правок.

## Внешние зависимости — контроль

Сейчас: **ноль** внешних SPM-зависимостей во всей линейке (DajetUI — локальный пакет линейки, не внешний) ✓. Единственный кандидат — tree-sitter в редакторе (E4): вопрос владельцу, без него — своя подсветка или отложить.
